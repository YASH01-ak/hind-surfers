# 🇮🇳 HIND SURFER

> **An India-themed endless runner game made for fun, practice, and entertainment.**

---

## 🎮 About HIND SURFER

**HIND SURFER** is a simple India-themed endless runner game built using **HTML, CSS, and JavaScript**.

Run through the Indian-themed environment, avoid obstacles, collect coins, jump, slide, and try to achieve a higher score.

The project is designed as a **fun coding and gaming project** and can be hosted easily using GitHub Pages.

---

## ✨ Features

* 🏃 Endless running gameplay
* 🇮🇳 India-inspired theme
* 🛣️ Three-lane running system
* 🚆 Train obstacles
* 🚧 Road barriers
* 🛺 Cart-style obstacles
* 🕳️ Potholes
* 🪙 Collectible ₹ coins
* 🏔️ Mountain background
* 🌳 Trees and environment
* 🏙️ City background
* 🦘 Jump mechanic
* 🧎 Slide mechanic
* 📈 Increasing game speed
* 🏆 Score system
* 🔄 Restart option
* 💻 Works with static hosting
* 🌐 GitHub Pages compatible

---

## 🕹️ Controls

| Key                 | Action     |
| ------------------- | ---------- |
| ⬅️ Left Arrow / A   | Move Left  |
| ➡️ Right Arrow / D  | Move Right |
| ⬆️ Up Arrow / Space | Jump       |
| ⬇️ Down Arrow / S   | Slide      |
| Enter               | Start Game |
